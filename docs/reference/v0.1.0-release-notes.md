# MiniContainer v0.1.0 release notes

v0.1.0は、RISC-V 64アプリケーションをQEMU仮想マシンで実行する学習用マイクロVMランタイムの最初の候補版である。

## 機能

- `minictr run`、`image build`、`image list`、`image inspect`、`help`、`--version`を提供する。
- 同梱の最小ゲスト例を静的RISC-V 64 ELFへbuildし、公開CLIだけで登録、検査、実行できる。
- MiniBundleの構築と検証、SHA-256 digest、content-addressed storeへの取り込み、tag付け、解決、一覧ができる。
- UART control frameの復元、終了コード、timeout、出力上限、Ctrl-C時の後始末、QEMU回収、一時領域削除を行う。
- `v0.1.0`タグのpushでmacOS arm64用とLinux x86_64用の配布アーカイブを構築する。

## 必要環境

- Rust 1.98.0、`riscv64gc-unknown-none-elf` target、QEMU 8.2.0以上、Git。
- Apple Silicon搭載macOSまたはUbuntu 24.04。
- Guest ABIは`minios-abi-v0.1.1`、実行kernelはminiOSの固定revisionからbuildする。

## 検証

- `cargo xtask setup`で開発環境を診断する。
- `cargo xtask check-host`で実QEMUを除く15段階を検証する。
- `cargo xtask check`で実QEMU end-to-end検証を含む16段階を検証する。
- Ubuntu CIは`setup`と`check`、macOS CIは`check-host`を実行する。
- E2Eは同梱ゲストの正常経路と、timeout、不正frame、出力上限、割り込みの失敗経路を確認する。

## 制約と既知の非対応

- MiniContainerは本番用のセキュリティー境界ではありません。
- 未信頼コードを扱うマルチテナント環境には使用しない。
- OCI互換、registry、Dockerfile、Linuxアプリケーション互換、ネットワーク、永続ボリューム、複数container連携、対話入力、リアルタイム出力には対応しない。
- `SIGTERM`と`SIGKILL`による強制終了では後始末を保証しない。
- Windowsには対応しない。
- 配布物の署名、notarization、GitHub Release作成は行わない。
